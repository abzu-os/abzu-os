# 🌊 Abzu
**An elegant, powerful operating system for desktops, workstations and homelabs that honours and preserves the ancient traditions. .**

Abzu is a multi-flavor operating system initiative designed to rescue vintage x86-64 and PowerPC hardware from the e-waste pile, providing a secure, modern, and beautiful desktop experience.

### 🍎 Abzu Darwin
Nix-based distribution built on the Apple XNU kernel. Features a custom GNUstep "Aqua" desktop, Cuneiform input, and OpenBSD userland tools. 
👉 [View the `abzu-darwin` Repository](https://github.com/abzu-os/Abzu)

### 👒 Abzu "Abyssolith"
Universal Blue / Fedora Atomic variant. Designed for broad modern x86-64 hardware compatibility with immutable, containerized workflows.
👉 [View the `abzu-abyssolith` Repository](https://github.com/abzu-os/Abzu-Abyssolith)
